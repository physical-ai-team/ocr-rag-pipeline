# 처음 세팅 가이드 (conda 처음 쓰는 사람용)

순서대로 따라 하면 된다. 한 번만 하면 되고, 30분 정도 걸린다.

---

## 0. conda가 뭔가요?

- 이 프로젝트의 백엔드(OCR, 임베딩 등)는 **Python**으로 만든다.
- Python 프로그램은 여러 **라이브러리**(남이 만든 코드 묶음)를 설치해서 쓰는데, 팀원마다 버전이 다르면 "내 PC에선 되는데 네 PC에선 안 돼" 문제가 생긴다.
- **conda**는 프로젝트 전용 **가상환경**(독립된 Python 설치 공간)을 만들어 주는 프로그램이다.
- 레포에 있는 `environment.yml` 파일에 "Python 3.11 + 이 라이브러리들"이 적혀 있고, 명령어 한 줄로 모두가 **똑같은 환경**을 만들 수 있다.

> 비유: `environment.yml` = 장보기 목록, conda = 그 목록대로 장을 봐서 전용 냉장고(가상환경)에 넣어주는 사람.

---

## 1. Miniforge 설치 (conda 설치)

**Miniforge** = conda를 설치하는 프로그램.

### Windows

1. https://github.com/conda-forge/miniforge/releases/latest 접속
2. 목록에서 **`Miniforge3-Windows-x86_64.exe`** 다운로드 후 실행
3. 설치 화면 선택:
   - **Just Me** 선택
   - 설치 경로는 기본값 그대로 (경로에 한글/띄어쓰기 있으면 문제 생길 수 있음 — 사용자 이름이 한글이면 `C:\miniforge3` 처럼 바꾸기)
   - 옵션 화면: **Create start menu shortcuts** ✅ / **Add Miniforge3 to my PATH** ❌ (체크하지 않기) / 나머지는 기본값
4. 설치 완료 후 시작 메뉴에서 **Miniforge Prompt** 실행 (검은 창이 뜸)
5. 아래 입력 후 Enter:
   ```
   conda --version
   ```
   `conda 24.x.x` 같은 버전이 나오면 성공.

### Mac

1. 터미널을 열고 아래 두 줄 입력:
   ```bash
   curl -L -O "https://github.com/conda-forge/miniforge/releases/latest/download/Miniforge3-$(uname)-$(uname -m).sh"
   bash Miniforge3-$(uname)-$(uname -m).sh
   ```
2. 질문이 나오면 Enter / `yes` 입력 (마지막 "conda init 할까요?"에도 `yes`)
3. 터미널을 껐다 켠 뒤 `conda --version` 으로 확인

## 2. VS Code 터미널에서도 conda 쓰게 하기 (Windows)

처음엔 conda가 **Miniforge Prompt** 안에서만 동작한다. VS Code 터미널에서도 쓰려면 한 번만 설정한다.

1. **Miniforge Prompt**에서:
   ```
   conda init powershell
   ```
2. 시작 메뉴에서 **Windows PowerShell** 실행 후 (보안 설정 허용):
   ```powershell
   Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
   ```
   물어보면 `Y` 입력.
3. **VS Code를 완전히 껐다 켜기**
4. VS Code 터미널(`` Ctrl + ` ``)에서 `conda --version` 이 나오면 성공. 앞에 `(base)` 가 보이면 정상.

---

## 3. 프로젝트 가상환경 만들기

VS Code에서 이 프로젝트 폴더를 연 상태로, 터미널에서:

```powershell
conda env create -f environment.yml
```

- 처음엔 몇 분 걸린다. 마지막에 `conda activate ocr-rag` 안내가 나오면 성공.
- 이건 **한 번만** 하면 된다.

---

## 4. 가상환경 켜기 (작업할 때마다)

```powershell
conda activate ocr-rag
```

터미널 맨 앞이 `(base)` → **`(ocr-rag)`** 로 바뀌면 켜진 것. 이 상태에서 Python 코드를 실행한다.

| 하고 싶은 것 | 명령어 |
| --- | --- |
| 가상환경 켜기 | `conda activate ocr-rag` |
| 끄기 | `conda deactivate` |
| 내 가상환경 목록 보기 | `conda env list` |
| 누가 `environment.yml` 바꿨다고 할 때 | `conda env update -f environment.yml --prune` |

---

## 5. VS Code에 가상환경 연결하기

Python 파일을 열었을 때 VS Code가 올바른 Python을 쓰도록:

1. VS Code 확장(Extensions)에서 **Python** (Microsoft) 설치
2. `Ctrl + Shift + P` → **Python: Select Interpreter** 입력
3. 목록에서 **`ocr-rag`** 가 들어간 항목 선택

---

## 6. 패키지(라이브러리)를 추가하고 싶을 때

`pip install 패키지명`만 하면 **내 PC에만** 설치되고 팀원은 모른다. 반드시:

1. `environment.yml`의 `pip:` 아래에 `- 패키지명==버전` 한 줄 추가
2. `conda env update -f environment.yml --prune` 로 내 PC에 설치
3. 커밋 → PR → 팀에 "environment.yml 바뀜, update 하세요" 공지

## 자주 나는 문제

| 증상 | 해결 |
| --- | --- |
| `'conda'은(는) 내부 또는 외부 명령...이 아닙니다` / `conda: The term 'conda' is not recognized` | **2번** 다시 하기. 급하면 Miniforge Prompt에서 작업 |
| PowerShell에 빨간 글씨로 `스크립트를 실행할 수 없으므로...` | 2번의 `Set-ExecutionPolicy` 실행 후 VS Code 재시작 |
| `conda env create` 때 `already exists` | 이미 만든 것. `conda env update -f environment.yml --prune` 사용 |
| 가상환경이 꼬였음 | `conda deactivate` → `conda env remove -n ocr-rag` → 3번부터 다시 |
| `conda activate` 했는데 `(ocr-rag)` 가 안 뜸 | VS Code 터미널을 휴지통 아이콘으로 닫고 새로 열기 |

그래도 안 되면 에러 메시지 전체를 복사해서 팀 채팅방에 올리기.

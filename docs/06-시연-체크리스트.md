# 시연 체크리스트

시연 당일 이 순서대로 하면 된다. 2026-10-27 폰 테스트에서 실제로 막혔던 것들을 반영했다.

## 전날까지

- [ ] `git switch main` → `git pull` → `npm ci` → `npm run build`
- [ ] `.env` 확인: `SUPABASE_URL`, `SUPABASE_KEY`(service_role), `GEMINI_API_KEY`, `GEMINI_MODEL=gemini-3.5-flash-lite`
- [ ] Supabase 프로젝트가 **일시정지 상태가 아닌지** 대시보드에 한 번 접속 (무료 플랜은 일주일 안 쓰면 멈춤)
- [ ] 한 번 전체 리허설 (아래 "당일 순서") 후 **RAG 평가** 돌려서 점수 확인: `python eval/rag_eval.py --out eval/result.md`
- [ ] 리허설 데이터 **Supabase 테이블 비우기** (다음 섹션 맨 아래)
- [ ] 폰 거치대 준비 (손으로 들면 흔들려서 OCR 이 거의 안 됨)
- [ ] VS Code 를 **완전히 껐다 켜서** `cloudflared` 명령이 바로 되는지 확인

## 당일 순서

### 1. 서버 켜기 (5분)

1. **Docker Desktop** 실행 → 고래 아이콘이 멈출 때까지 기다리기
2. VS Code 터미널 1:
   ```powershell
   docker compose up -d --build
   ```
3. VS Code 터미널 2 (켜 둔 채로 둔다):
   ```powershell
   cloudflared tunnel --url http://localhost:8000
   ```
   `cloudflared` 를 못 찾으면: `& "C:\Program Files (x86)\cloudflared\cloudflared.exe" tunnel --url http://localhost:8000`
4. 나온 `https://….trycloudflare.com` 주소를 PC 브라우저로 연다 (**localhost 로 열면 QR 이 폰에서 안 열린다**)

### 2. 화면 띄우기

1. 메인 화면 오른쪽 위 **[컨베이어 열기]** → 새 탭 → **F11 (전체 화면, 주소창이 찍히면 저장이 안 됨)**
2. 컨베이어 오른쪽 패널 설정:
   | 항목 | 값 | 이유 |
   | --- | --- | --- |
   | 서체 | **Sans** | Serif 는 OCR 인식률이 많이 떨어짐 |
   | 글자 크기 | **24~28px** | 기본 14px 은 폰으로 찍으면 너무 작음 |
   | 이송 속도 | **20~30 px/s** | 빠르면 흔들림·놓침 |
   | 지면 | 흰 종이 / 검은 글씨 | |
3. 메인 탭에서 **[대시보드 열기]** → 컨베이어 창과 좌우로 나란히 (`Win + ←` / `Win + →`)
4. 대시보드 ②에 노란 "모델을 불러오는 중" 문구가 **사라질 때까지** 기다린다 (보통 1분 이내). 그 전에 찍은 화면은 저장되지 않는다.

### 3. 폰 연결

1. 대시보드 ① QR 을 폰 카메라로 스캔 → **카메라 켜고 전송 시작** → 카메라 권한 허용
2. 대시보드 ① 이 **● 연결됨** 으로 바뀌고 받은 프레임 수가 올라가면 성공
3. 폰을 거치대에 고정하고 컨베이어 창을 비춘다
   - 카드 한 장이 화면의 **70~80%** 를 차지하게, **양옆에 여백이 조금 보이게** (글자가 화면 끝에 닿으면 "잘린 카드"로 보고 버림)
   - 모니터와 **정면으로 평행**. 줄무늬(모아레)가 심하면 살짝 기울이거나 모니터 밝기를 낮춘다
4. 컨베이어 **재생** (Space)

### 4. 보여 줄 것

- ② 저장 현황: `N / 100 지문 저장` 이 올라가고, **지문** 탭에 카드 제목이, **문장** 탭에 저장된 문장이 실시간으로 쌓인다
- ③ RAG 검색: 컨베이어는 1번 카드부터 흘러가므로 **앞쪽 카드 질문**을 쓴다. 대시보드 ② 지문 탭에서 저장된 제목을 보고 고른다.

  | 카드 | 질문 | 정답 |
  | --- | --- | --- |
  | 001 The Quiet Machinery of Cities | When were the cast-iron water pipes laid down? | 1897 |
  | 002 Notes on Reading Speed | How many words per minute does an average adult read on paper? | 240 |
  | 003 A Letter from the Coast | 편지에서 안개는 무슨 요일에 왔어? | 화요일 |
  | 004 Quarterly Operations Summary | What was the total throughput in Q3? | 1,482,600 |
  | 006 Field Notes: Migratory Birds | 제비는 번식지에서 최대 몇 km 떨어진 곳에서 겨울을 나? | 9,000 km |
  | 007 The Repair Shop | How many drawers did Dessin's workbench have? | 400 |
  | 008 Instructions for the New Kettle | 주전자 석회 제거할 때 식초를 얼마나 써? | 250 ml |
  | 009 A Short History of Paper | When did paper reach Baghdad? | 793 |
  | 010 Weather Log — 14 March | How much rain was recorded by nightfall? | 3.2 mm |
  | 011 The Cartographer's Complaint | Which place swells on flattened maps? | Greenland |
  | (없는 내용) | What is the capital of France? | "찾을 수 없음" — 지어내지 않는 것을 보여 준다 |

  전체 질문 42개와 정답은 `eval/rag_questions.json`.

### 5. 끝나면

1. 터널 터미널에서 **Ctrl + C** (열려 있는 동안은 주소를 아는 누구나 접속 가능)
2. `docker compose down`

## 문제가 생기면

| 증상 | 원인 / 해결 |
| --- | --- |
| 터널 주소로 열었는데 메인 화면만 나옴 | 정상. 메인의 **[컨베이어 열기]** / **[대시보드 열기]** 버튼을 누른다 |
| `cloudflared` 를 찾을 수 없음 | VS Code 를 완전히 재시작하거나 전체 경로로 실행 (위 1-3) |
| QR 아래에 노란 "localhost" 경고 | 대시보드를 localhost 로 열었음 → 터널 주소로 다시 열기 |
| 폰에서 카메라가 안 켜짐 | https(터널) 주소인지 확인. 폰 브라우저 카메라 권한 확인 |
| 연결됨 + 프레임은 오는데 문장이 안 쌓임 | ① 주소창이 찍힘 → F11 ② 글자가 작음 → 24px 이상, Sans ③ 카드가 화면 끝에 닿음 → 폰을 조금 뒤로 ④ 노란 "모델 불러오는 중" 문구가 떠 있음 → 기다리기 |
| ② 에 빨간 "pipeline 에 연결할 수 없음" | `docker compose ps` 로 pipeline 이 떠 있는지 확인 → `docker compose up -d` |
| ② 에 노란 "메모리에 저장 중" | `.env` 에 Supabase 키가 없음 → 키 넣고 `docker compose up -d --force-recreate` |
| RAG 가 "LLM 응답 실패" | Gemini 무료 한도·혼잡. 근거 문장은 그대로 보인다. 잠시 후 다시 질문 |
| 같은 카드를 다시 찍어도 저장이 안 늘어남 | 정상 (중복 저장 방지). 다른 카드를 찍는다 |
| 지문 수가 이상하게 많음 (같은 제목이 둘) | OCR 이 제목을 많이 틀리게 읽음. 문장 탭은 정상이니 시연은 계속 |

## Supabase 테이블 비우기

리허설 데이터를 지울 때 (되돌릴 수 없음, **팀에 먼저 공유**):

```powershell
docker compose exec pipeline python -c "from app.pipeline import make_store; s = make_store(); s.reset(); print('남은 행:', s.count())"
docker compose restart pipeline
```

`restart` 는 pipeline 이 기억하는 "이미 본 문장" 목록까지 비우기 위해 필요하다 (안 하면 같은 카드를 다시 찍어도 중복으로 보고 저장하지 않는다).
